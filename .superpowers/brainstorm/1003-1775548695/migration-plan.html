Mizan Frontend Migration Plan

Take the full UI from mizan-ai-web-app-main as the base, wire it to the real Mizan backend. Here's exactly what maps where.

✅ Take from mizan-ai-web-app-main (UI/UX)
Design System
Full Tailwind config, CSS variables, light/dark mode, all shadcn/ui components, animations
Shell
AppSidebar (collapsible), AppHeader (search, theme toggle, user menu, notifications), AppLayout
Dashboard Components
StatsCards, ComplianceChart, RecentUploads, QuickActions, ActivityTimeline
Chat UI
FloatingChatButton, ChatInterface, ChatMessage — all the chat components
Page shells
Upload, Documents, Reports, Settings — layouts and UI patterns
🔌 Wire to real Mizan backend
Auth → Real JWT
Replace localStorage mock auth with real /auth/login, /auth/register, refresh token rotation, Zustand store
Dashboard → Real data
Stats from GET /projects. Chart from project history. Activity from GET /activity.
Upload → Project + 2-doc flow
Create project → upload Doc A (requirements) + Doc B (compliance) → trigger analysis. Real progress via polling.
Documents → Projects list
GET /projects — list with status badges, scores, links to analysis results.
Analysis Results — new page
Score gauge, tabs: Summary / Requirements / Gaps / Chat. Wire to /analysis, /requirements, /gaps, /ai/chat.
Reports → Real export
List completed analyses, download PDF/JSON reports via /projects/:id/report.
